## Caller-ID support for ZoiteChat and HexChat

Caller-ID is an IRC user mode that prevents unwanted private messages. Useful in public support channels. 

This script handles the [OFTC](https://oftc.net/CallerId/) and [Libera.Chat](https://libera.chat/guides/usermodes) implementations and may work with few modifications on other networks.
